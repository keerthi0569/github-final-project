# Simple Interest Calculator

A simple calculator to compute simple interest based on user input.

## Description
This is a simple interest calculator written in Bash. It calculates simple interest using the formula: Interest = (Principal * Rate * Time) / 100

## How to use
1. Clone the repo
2. Run `bash simple-interest.sh`
3. Enter principal, rate of interest and time period
4. The script will display the simple interest
